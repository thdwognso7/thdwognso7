## GitHub 저장소 연결 가이드

현재 로컬 프로젝트를 GitHub에 연결하려면 다음 단계를 따르세요.

### 1단계: Git 설치
먼저 시스템에 Git이 설치되어 있어야 합니다. [Git for Windows](https://git-scm.com/download/win)에서 다운로드하여 설치할 수 있습니다.

### 2단계: 저장소 초기화 및 연결
터미널에서 다음 명령어를 실행하거나, 함께 생성된 `connect_git.bat` 파일을 실행하세요.

```bash
# Git 초기화
git init

# 모든 파일 추가 및 커밋
git add .
git commit -m "Initial commit"

# 원격 저장소 연결 (main 브랜치 설정)
git branch -M main
git remote add origin https://github.com/thdwognso7/thdwognso7.git

# GitHub로 푸시
git push -u origin main
```
